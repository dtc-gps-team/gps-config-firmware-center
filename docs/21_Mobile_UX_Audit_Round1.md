# UX Audit — Mobile App (รอบแรก, 16 ต.ค. 2569)

รายการปัญหา UX 25 ข้อจาก audit รอบแรกของแอป Mobile และสถานะการแก้ไข ณ ปัจจุบัน

> **ที่มา:** audit ทำบน `main` ที่ `bd551e1` ใน mock mode บน emulator (Pixel_10a) วันที่ 16 ต.ค. 2569
> ตรวจทั้งจากการใช้งานจริงบนเครื่อง, widget probe (3 ขนาดจอ × 3 ขนาดตัวอักษร) และการอ่านโค้ด
> เดิมรายงานอยู่แค่ใน transcript ของ session ที่ทำ audit เอกสารนี้ย้ายเข้ามาไว้ใน repo ให้อ้างอิงได้
>
> **สถานะ:** ยืนยันจากโค้ดใน `main` ที่ `6c341a5` (19 ต.ค. 2569)
>
> **เอกสารที่เกี่ยวข้อง:** `docs/18` (Phase 1-2 สำรวจหน้าจอ), `docs/20` (Phase 3 แผน redesign)
